## 🛠️ Hecho con

- **HTML**: la estructura
- **CSS**: el diseño
- **JavaScript**: la interacción y el sonido

No usa librerías ni frameworks: es un solo archivo, `index.html`, hecho a mano para entender cada parte.

## 💻 Cómo verlo en tu computadora

1. Descargá o cloná el repo:
   ```bash
   git clone https://github.com/Nicanor-Al/Nicanor-Al.github.io.git
   ```
2. Abrí `index.html` con cualquier navegador.

No hace falta instalar nada.
